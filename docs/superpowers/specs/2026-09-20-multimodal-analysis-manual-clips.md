# 多模式影片分析與手動片段設計

## 目標

在現有本機影片剪輯 MVP 上，加入三種影片分析路徑，並允許使用者以開始／結束時間手動新增片段。所有 AI 與手動片段都共用現有的字卡編輯、預覽、渲染與下載流程。

## 分析模式

- 一般講話：以 Whisper 逐字稿、語意、情緒與關鍵句挑選候選片段。
- 音樂／圖片背景：以音量峰值、節奏變化、畫面切換與亮度變化建立候選片段。
- 安靜影像：以影格差異、場景切換、畫面移動與停留時間建立候選片段。
- 混合內容：可同時使用語音與影音特徵，不能因缺少逐字稿而使整個分析失敗。

## 手動片段

使用者可輸入開始時間與結束時間新增片段。系統必須驗證時間為有效數字、開始時間不小於 0、結束時間大於開始時間，且不能超過原始影片長度。手動片段加入候選清單後，使用與 AI 片段相同的資料欄位與操作流程，並標記 `source: manual`。

## 錯誤處理

音訊不存在、Whisper 無法辨識或 Gemini 沒有有效 JSON 時，系統仍應嘗試使用可用的影音特徵；只有所有分析路徑都失敗時才回傳錯誤。錯誤訊息必須指出失敗階段與可採取的下一步。

## 相容性

現有 `main` 分支維持目前可工作的 MVP。所有本功能變更只在 `feature/multimodal-analysis-manual-clips` 分支進行，不修改或刪除既有使用者提供的設計文件。

## 驗收條件

1. 有人聲影片可繼續產生 AI 候選片段。
2. 只有音樂或無聲影片不會因 Whisper 沒有文字而直接失敗。
3. 使用者可以新增有效的手動片段並預覽、編輯、渲染與下載。
4. 無效時間輸入會在前端提示，後端也會再次驗證。
5. 現有前端 build 與後端測試持續通過。
