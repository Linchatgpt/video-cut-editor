# Reel 字卡編輯器 UI 修改規格

## 目標

將目前的影片片段編輯頁整理成「先選片段 → 調整片段時間 → 編輯文字 → 直接預覽 → 個別輸出」的單一工作流程。

保留目前深色、粉色、薄荷綠的視覺語言，但降低框線密度，讓預覽與目前選取狀態成為畫面主角。

## 目前問題

- 預覽區太小，無法確認文字套用到影片上的實際效果。
- 時間資訊、AI 建議時間與實際輸出時間的關係不夠清楚。
- 右側字卡設定同時承擔太多功能，缺少群組與優先順序。
- `渲染這支 Reel`、`預覽片段`、`下載這支 Reel` 的流程關係不夠明顯。
- 桌面版右側控制區過窄，長文字和下拉選單容易被截斷。

## 目標版面

桌面版採用三區工作台。時間軸屬於中央預覽區，必須與中央預覽的左右邊界對齊，不放在整個頁面的最底部：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ Reel Studio                         已自動儲存                       │
├──────────────┬─────────────────────────────────────┬───────────────┤
│ 片段清單      │ 影片預覽                             │ 字卡設定       │
│              │ ┌─────────────────────────────────┐ │ 上欄 / 下欄    │
│ 01 00–13 秒  │ │                                 │ │ 文字輸入       │
│ 02 13–26 秒  │ │          9 : 16 影片            │ │ 字型 / 顏色    │
│ 03 26–41 秒  │ │       上欄文字 / 下欄文字        │ │ 字級           │
│              │ └─────────────────────────────────┘ │ X / Y 位置     │
│ AI 建議時間  │ ▶ 00:04 / 00:13     ━━━━━●━━       │ 動畫效果       │
│              │                                     │               │
│               ├───────────────┤                                  │
└───────────────┴─────────────────────────────────────┴───────────────┘
```

## 元件與互動規格

### 1. 頁首

- 左側顯示 `Reel Studio` 與目前檔名。
- 中間顯示狀態：`已自動儲存`、`正在儲存…`、`儲存失敗`。
- 右側只顯示儲存狀態，不放置 `開始渲染` 或批次渲染按鈕。
- 渲染操作只放在目前片段的設定區，由使用者逐一執行。

### 2. 片段清單

- 每個片段顯示：編號、AI 產生的片段標題、實際時間範圍、是否已編輯。
- 清單中的主標題必須使用 `clip.title`；禁止使用「預覽片段」、「第二段片段」等通用替代文案。
- 若 `clip.title` 為空，才顯示「未命名片段」，並讓使用者可以直接編輯標題。
- 點擊片段後，中央預覽與右側設定同步切換。
- 目前選取片段使用粉色左邊框與淡色背景。
- 片段列上的主要文字是片段標題；播放功能使用獨立的播放圖示按鈕，不要把「預覽片段」當成片段名稱。
- AI 建議時間使用薄荷綠標籤，例如 `AI 建議 0.0–13.0s`。
- 不要將所有片段的完整編輯器同時展開；一次只展開目前選取片段。

### 3. 中央影片預覽與時間軸

- 使用真正的影片畫面，不使用抽象色塊取代。
- 固定直式 9:16 比例，最大高度約 560px。
- 文字直接疊在影片上，顯示目前的上欄與下欄文字。
- 點擊文字可選取該文字；拖曳可修改位置。
- 影片下方提供：播放／暫停、目前時間、總長度、時間軸播放頭。
- 時間軸必須緊貼中央預覽區下方，且左右邊界與中央預覽欄完全對齊。
- 不要把時間軸獨立放到整個頁面最下方；使用者調整預覽時，時間軸必須保持在視線附近。
- 時間軸寬度以中央預覽欄為準，不跨越左側片段清單或右側字卡設定。
- 時間軸片段可拖曳左右邊界，修改 `start_time` 與 `end_time`。
- 每個 AI 建議片段都必須能獨立調整 `start_time` 與 `end_time`。
- 片段時間調整提供兩種方式：拖曳時間軸左右邊界，以及輸入精確秒數。
- 顯示兩組數值：`AI 建議 0.0–13.0s` 與 `目前輸出 1.5–11.8s`。
- 時間不能小於 0、不能超過影片長度，且 `end_time` 必須大於 `start_time`。
- 調整時間後只影響目前片段，不得連動修改其他片段。

### 4. 右側字卡設定

依以下順序排列：

1. `正在編輯：上欄文字／下欄文字`
2. 文字輸入框
3. 字型與字級
4. 顏色與描邊／陰影
5. X 軸、Y 軸位置
6. 動畫效果（第一版可先保留 disabled 或顯示「即將推出」）

- 上欄／下欄使用 segmented control，不使用大型獨立按鈕。
- 所有設定修改後立即更新中央預覽。
- 滑桿旁顯示數值，例如 `X 軸 50%`、`Y 軸 22%`。
- 提供 `重設位置`，將文字回到預設位置。
- 下拉選單不可被窄欄截斷；桌面版設定欄最小寬度 320px。

### 5. 個別渲染與輸出狀態

- 每個片段都要有自己的 `渲染此片段` 按鈕，不需要等待或渲染其他片段。
- 個別渲染時只送出目前片段的資料：目前標題、目前 `start_time`、`end_time`、文字與字卡設定。
- 個別渲染按鈕只在目前片段渲染期間 disabled，其他片段仍可編輯。
- 渲染中顯示 `渲染中…`；完成後顯示該片段的影片預覽與 `下載此片段`。
- 不提供頁首批次渲染按鈕；本產品原則上由使用者逐一渲染片段。
- 渲染完成後，在同一個片段的結果區顯示影片預覽與 `下載此片段`。
- 下載按鈕使用明確文字，不只使用下載圖示；手機上也要保持至少 44px 高。
- 失敗時顯示具體原因與 `再試一次`，不要只顯示模糊的錯誤訊息。

## 視覺規格

```text
背景       #101214
面板       #171A1C
輸入框     #0C1011
主要粉色   #F2B8A2
AI 綠色    #A5D6A7
互動藍色   #2F80ED（僅用於播放頭、焦點或選取控制）
主要文字   #F4F0E8
次要文字   #A9B0AE
邊框       #303536
```

- 主按鈕與目前選取狀態使用粉色。
- AI 建議、完成狀態使用薄荷綠。
- 藍色只代表可互動的播放／定位元素，不再用作主要字卡色彩示意。
- 保留直角或 3–6px 小圓角，不使用大量膠囊形元件。
- 確保文字與背景有足夠對比；焦點狀態需有清楚外框。

## Responsive

- 1200px 以上：三欄工作台。
- 768–1199px：片段清單縮成可收合側欄，右側設定維持 300px。
- 767px 以下：改為單欄，順序為「片段選擇 → 片段時間 → 預覽 → 字卡設定 → 個別渲染」。
- 片段清單改為可橫向滑動的片段列，或使用底部片段選擇器；避免每個片段都長篇縱向展開。
- 影片預覽固定在上方，設定面板可向下捲動；不要讓手機使用者在預覽與控制項之間頻繁跳頁。
- 時間軸左右邊界的拖曳熱區至少 44px；滑桿與按鈕也至少 44px 高或寬。
- 精確時間輸入使用數字鍵盤，欄位旁顯示 `秒`，並支援 `0:01.5` 這類時間格式或清楚拒絕格式錯誤。
- 個別渲染按鈕固定在目前片段設定區底部，確保使用者不必回到頁首才能輸出。
- 手機上顯示 `渲染此片段`，不要只使用不易辨識的圖示。
- 手機輸入框至少 44px 高，避免瀏覽器自動縮放。

## 實作限制

- 優先修改 `client/src/App.jsx` 與 `client/src/styles.css`。
- 保留既有 API：`/api/upload`、`/api/analyze`、`/api/render`。
- 保留既有資料欄位：`start_time`、`end_time`、`top_text`、`caption`、`style`、`renderedUrl`。
- 不要在此次修改中新增第三方 UI 套件。
- 將片段選取狀態集中管理，例如 `selectedClipId`，不要只依賴每張卡片自己的 `open` state。
- 將渲染狀態綁定到片段 id，例如 `renderingClipIds` 或每個 clip 的 `rendering`，不可用單一全域 loading 狀態鎖住所有片段。
- 新增可編輯片段標題的欄位，沿用 `clip.title`，並在時間或標題修改後保留使用者修改結果。

## 驗收條件

- 使用者能在 3 秒內辨識目前選取的片段。
- 每個片段清單項目顯示實際片段標題，而不是「預覽片段」或「第二段片段」等位置型文案。
- 每個片段可獨立修改起始時間與結束時間，且不影響其他片段。
- 修改文字、顏色、字級、X/Y 位置後，中央預覽立即更新。
- 預覽畫面呈現真實影片，不再只顯示兩個色塊。
- 時間軸可看見目前片段範圍與播放頭。
- 桌面版右側所有控制項不被截斷。
- 每個片段的個別渲染 loading、成功、失敗三種狀態清楚可見，且不會鎖住其他片段。
- 手機上可不依賴 hover 完成任何關鍵操作，所有拖曳控制與按鈕都有足夠觸控尺寸。
- 鍵盤可操作片段選擇、文字輸入、按鈕與滑桿，並有 visible focus。
- `npm test` 與前端 build 通過。

## 建議實作順序

1. 先抽出三欄版面與 `selectedClipId`。
2. 讓片段清單使用 `clip.title`，並補上標題編輯。
3. 將影片預覽移到中央並加入字幕疊加。
4. 補上每個片段獨立的時間軸範圍、起訖輸入與驗證。
5. 將設定區改成單一選取片段的控制面板。
6. 實作每個片段獨立渲染、下載與錯誤狀態。
7. 補齊手機版片段選擇、觸控拖曳與固定輸出操作。
8. 最後調整色彩、間距、focus state 與測試。
