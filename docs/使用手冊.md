# Reel Studio 使用手冊

Reel Studio 是一個把長影片剪成短片段的影片編輯工具。你可以先讓 AI 找出候選片段，再調整片段時間、文字、比例、音樂與音量，最後渲染並下載影片。

## 快速開始

### 1. 開啟網站

開啟 Reel Studio 網站後，可以直接使用預設影片，或按「選擇長影片」上傳自己的影片。

支援的影片格式包括：

- MP4
- MOV
- WebM
- MKV

### 2. 分析影片

在「AI 分析參數」中設定：

- 片段數量：希望 AI 找出幾個候選片段
- 每段秒數：每個片段的預設長度

按「開始分析預設影片」或上傳影片後開始分析。分析完成後，候選片段會出現在左側的「候選片段」欄位。

## 選擇與預覽片段

左側會列出每個候選片段的名稱、目前時間範圍與 AI 建議時間。

- 點選片段卡片：切換目前正在編輯的片段
- 按片段卡片右側的播放按鈕：開始播放
- 再按一次：暫停播放

中央「預覽」區域會顯示目前片段、字卡與輸出比例效果。

## 編輯字卡

右側「編輯字卡」區域可以調整目前片段的設定。

### 片段基本設定

- 片段主題名稱：修改片段在左側卡片與預覽上方顯示的名稱
- 輸出比例：選擇原始比例、9:16 Reels 或 1:1 正方形
- 背景音樂：選擇要加入的音樂

選擇「原始比例」會保留上傳影片的寬高比例。

### 上欄與下欄文字

按「上欄」或「下欄」切換要編輯的文字區域，兩個區域可以分別設定：

- 文字內容
- 出現時間
- 消失時間
- 字型
- 字級
- 顏色
- X 軸位置
- Y 軸位置

文字時間是以目前片段的開始位置為 0 秒。例如輸入出現時間 3 秒，代表文字會在片段開始後第 3 秒出現。

## 加入與調整背景音樂

在「背景音樂」下拉選單選擇音樂後，可以看到兩個音量滑桿：

- 音樂音量：調整背景音樂大小
- 原影片音量：調整影片原本的聲音大小

按「試聽此片段」可以同時預覽影片聲音與背景音樂。兩個音量設定會套用到最後的渲染結果。

將原影片音量調到 0%，輸出的影片會移除原本的影片聲音；將音樂音量調到 0%，則不會輸出背景音樂。

## 調整片段時間與位置

在「位置與渲染」區域可以調整：

- X 軸：文字左右位置
- Y 軸：文字上下位置
- 片段開始時間
- 片段結束時間

時間可以輸入到小數點第一位，例如 `12.5` 秒。按「重設位置」可以恢復目前文字區域的預設位置。

## 渲染與下載

完成設定後，按「渲染此片段」。等待處理完成後，右側會出現渲染結果：

1. 在播放器中確認影片與聲音。
2. 按「下載此片段」保存 MP4 檔案。

如果修改了文字、時間、比例、音量或音樂，需要重新渲染，新的設定才會出現在輸出影片中。

## 手動新增片段

當 AI 沒有找到想要的內容時，可以手動新增片段：

1. 在「手動新增片段」輸入開始時間。
2. 輸入結束時間。
3. 按「新增片段」。
4. 在右側編輯片段名稱、文字、音樂與其他設定。

手動片段會自動命名為「手動片段」、「手動片段2」等，之後可以在「片段主題名稱」欄位中修改。

## 手機使用

手機使用時，建議將網站加入主畫面：

- Android Chrome：開啟瀏覽器選單，選擇「安裝 App」或「加入主畫面」
- iPhone Safari：按分享按鈕，選擇「加入主畫面」
- 桌面 Chrome／Edge：使用網址列右側的安裝圖示

手機瀏覽器可能限制直接調整 HTML5 影片的音量，因此請以渲染後的影片作為最終聲音確認。渲染時會由伺服器依照「原影片音量」與「音樂音量」重新處理聲音。

## 常見問題

### 修改後為什麼影片沒有變化？

預覽畫面只反映目前編輯狀態；要產生可下載的新影片，必須重新按「渲染此片段」。

### 為什麼看不到候選片段？

請先完成影片上傳與分析。分析完成後，片段才會出現在左側清單。

### 為什麼下載失敗？

請確認渲染已完成，並重新整理頁面後再按下載。如果後端服務暫時沒有回應，請稍後重新渲染。

### 可以只保留背景音樂嗎？

可以。將「原影片音量」調為 0%，並保留背景音樂音量，再重新渲染即可。
